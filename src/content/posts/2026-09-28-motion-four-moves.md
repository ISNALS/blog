做片子的时候我会数一件事：**这一分钟里出现了几种动效手法**。

数出来的数字越大，片子越难看。这不是审美偏好，是我踩过很多次的坑——第一版总是恨不得每个元素都飞进来、都发光、都弹一下，最后看起来像一份特效 demo 而不是一支片子。

所以这次搭博客，我给自己定了个规矩：**全站只允许四个动作**。

## 四个动作是什么

| 动作 | 作用 | 用在哪 |
|---|---|---|
| 模糊化开 | 让元素"从雾里显形" | 所有入场 |
| 上浮 | 建立层次，告诉眼睛"这是新的" | 所有入场 |
| 放大到位 | 给一次极轻的呼吸感 | 标题、封面图 |
| 淡入 | 收尾，把注意力交给内容 | 所有入场 |

关键在于：这四个动作**不是四个选项，而是同一次入场的四个通道**。同一个元素同时做这四件事，用同一组时长和同一条缓动曲线。

```css
[data-reveal] {
  opacity: 0;
  filter: blur(14px);
  transform: translate3d(0, 18px, 0) scale(0.985);
  transition:
    opacity 620ms var(--ease-out),
    filter 620ms var(--ease-out),
    transform 1000ms var(--ease-out);
}
```

注意 transform 的时长（1000ms）比 opacity / filter（620ms）更长。这是刻意的：**模糊散开和位移动到位不该在同一时刻结束**。如果三个通道同时收尾，画面会读作"图层属性被改完了"；错开之后才读作"东西显形了"。

## 错峰才是主角

单个元素的入场其实无所谓——**节奏感全部来自错峰**。

博客首页的卡片是这样排的：每张卡比前一张晚 70ms，并且上限封在 560ms。

```ts
el.style.setProperty('--delay', `${Math.min(i * 70, 560)}ms`);
```

为什么要有上限？因为如果按"每张卡 +70ms"线性铺开，满十张卡时最后一张要等 700ms，用户的等待感就变成了"这站好慢"。封顶之后，前几张读作"铺开"，后面的读作"一起来"——眼睛不会去数。

## 文章内的文字也要过渡

这是我觉得最容易被忽略的一层：**文章之间**的过渡大家都做，**文章内部**的过渡很少人做。

我的做法是给正文的每个直接子元素（段落、图、引用、代码块）挂同一个揭示，错峰收到 40ms：

```ts
kids.forEach((el, i) => {
  el.setAttribute('data-reveal', '');
  el.style.setProperty('--delay', `${Math.min(i * 40, 240)}ms`);
});
```

40ms 的间隔读起来不是"一块一块弹出来"，而是"一段接一段浮上来"——像视线在往下走，而不是页面在跳。

标题则用逐字揭示。中日韩没有空格分词，所以切片策略是：拉丁词整词算一个单位，汉字逐字算一个单位，标点跟着前一个字。标题短，逐字反而是它最好看的形态。

## 最后一件小事：动效开关

写动效必须处理 `prefers-reduced-motion`。这不是可选项——有人会因为前庭功能障碍而晕动效，而这个设置就是他们告诉你的方式：

```css
@media (prefers-reduced-motion: reduce) {
  [data-reveal] { opacity: 1 !important; filter: none !important; transform: none !important; }
}
```

一行都不省。省掉的后果是有人打不开你的站。
